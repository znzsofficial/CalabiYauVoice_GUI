## 修改与证据

### 地图

- `MapDetailParsers` 的 CSS body 正则末尾未转义 `}`。桌面 JVM 接受，Android 使用的 ICU 拒绝；本机原生 ICU 精确复现 `U_REGEX_RULE_SYNTAX / offset 49`。
- 修复为 `\}`，原生 ICU 编译通过；保持背景图域名约束、地形图、简介、图库和缓存行为。新增两张报告地图的合成背景回归，已有裂隙真实 fixture／完整快照继续执行；没有声称抓取了新的莱布伦城页面。

### 掉落图鉴

- 11 月 3 日实际四页巡检：简介、159 战利品、127 配件及去重后的 53 掉落来源可见内容未变。掉落页 `revid=119361` 去除重复卡片，总览表改为按稀有度分行与 `rowspan` 合并元信息。
- 新表原有解析会漏整份完整池。现兼容新旧表头，恢复 52 条完整池、249 个 Q 分组；每一来源的完整文本、合并边界与件数分布都有回归。数量是当日快照，不硬编码，也不等同于游戏新增数量。
- 同名同档次的晶骸核心按原始单元格归组，保留不同分布；不推测阶段、不按相似名称把卡片与总览表强行合并。
- 来源与完整池分视图、计数及类别筛选；详情分组默认 8 项，可搜索、展开全部。旧表仍能读取和搜索，保留 `extraction_*_v1` 原始 HTML 离线缓存。
- Q8 原样保留，未套成 Q1–Q5 的中文稀有度；空投无池内容不编造物品；权重、必掉物、件数概率、难度／档次独立展示。

### 骨架与文案

- 骨架头部增加双视图切换占位，删除已移除长说明的占位；对齐搜索框、筛选／计数行和摘要。
- 文本卡片补齐件数行，按主题文字行高占位标题、分类、件数、两行摘要与详情入口；仍无虚构图片或物品稀有度。文字高度及切换宽度跟随系统字体，FlowRow 可换行；保留统一加载无障碍语义。
- 平衡页删除草稿／取消路径的长篇说明、重复对比预览及“数值变化不代表角色强弱”等防御式文案；保留对比赛季、百分点、S8 表现分说明。未改查询、筛选草稿、应用／取消、重置、排序或差值计算。
