## 兼容性与边界

- Android 最低版本仍为 API 25，没有提升系统门槛。
- 下载恢复是回到页面后明确继续，不是可靠后台自动下载或字节级断点续传。
- 旧两列下载清单保留原文件名，但首次继续会重新下载以建立长度/哈希；未归属的用户同名文件不覆盖。
- WebView 导航策略不是子资源网络防火墙；弹窗无法重建的表单不会被静默改成 GET 重发。
- 本次没有数据库结构变化，不新增或重复执行 D1 迁移；已上线的 0010 继续保留。
- 没有连接真机，不能把自动测试、Lint 或签名验证表述为真机登录/权限/渲染进程回收已验证。

## 发布校验

发布前执行 Android/shared/Desktop 测试、Android Lint、Svelte 类型检查、赛季/展示回归和 Worker 集成测试。
随后构建签名 release APK，核对版本/证书，执行既有 R2 上传与 Pages 生产部署，并校验线上元数据、APK SHA-256 和 Range。
发布准备提交中的 apkSize=0 是未上线的占位值；webDist 将在构建后写入真实大小、SHA-256 URL 指纹和归档记录，
不得把占位元数据直接部署到 Pages。最终产物信息在发布验证后补全。
