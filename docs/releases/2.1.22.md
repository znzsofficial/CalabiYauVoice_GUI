## 面向用户的更新日志

1. 修复部分手机下载语音时出现 Could not publish download manifest：下载记录改存应用内部，不再往下载目录写隐藏清单。
2. 下载不再因系统网络未验证或恢复记录保存失败而整批中断；某个分类获取失败时，已取到的分类仍会下载。
3. 下载失败时保留已有文件，不再先删除再重下。
4. 应用更新安装成功后，下次打开会清理应用专属目录里残留的更新安装包；未确认安装成功的不会删除。
5. 更新 Compose 1.12.2、OkHttp 5.5.1、WebKit 1.18.0、Material 3 1.5.0-beta02、Palette 1.1.0 与 kotlinx-serialization 1.12.0。

## 本次收尾范围

- Android 下载记录改到 `filesDir/download_manifests`，按保存目录隔离；旧公共清单只读导入，读不到也不阻断。
- 网络状态和恢复记录只提示，不再作为下载门槛。分类查询失败不会丢掉已取到的文件，也不会显示成空结果。
- 清单只在名称变化和本批新指纹时发布；取消时先等子任务结束再复制清单。调度层不再先删除目标。
- 更新安装包只在 PackageManager 确认目标版本已安装、且路径属于应用专属目录时清理。
- 依赖升级见 `gradle/libs.versions.toml`，没有单独的行为承诺。

## 兼容性与边界

- Android 最低版本仍为 API 25。
- 下载恢复仍是回到页面后明确继续，不是后台自动下载或字节级断点续传。
- 卸载或清除应用数据会丢失私有下载记录。没有可读旧清单时，同名现有文件仍保留，新任务可能生成带后缀的副本。
- 没有真机复现原来的清单发布失败，不能把公共目录音频文件本身的权限问题也说成已解决。
- 没有连接设备，不能把自动测试或签名验证表述为真机更新安装清理已验证。
- 本次没有数据库结构变化，不新增或重复执行 D1 迁移。
