# 2.1.27（57）发布记录

日期：2026-11-06。状态：**已发布，源码／元数据已推送，R2 与三域名验证通过**。

## 范围与用户更新日志

上次发布元数据 `d25cce8`，后续 `d1d6ccd` 是 2.1.26 收尾文档。本次覆盖此后掉落查询、角色详情排版、Tab 背景与 Hub 转场工作区，以及本次复审修复。Android 2.1.27 / 57，Desktop packageVersion 同步。

1. 掉落图鉴新增逐来源完整池与物品反查，支持按物品名称和品质查询来源，明确编号的来源可直达对应完整池。
2. 完善掉落筛选、池内搜索和展开状态恢复，区分候选池与实际出货，反查默认排除件数恒为零的来源。
3. 优化超弦体详情的技能排版与展开体验，技能区前移并保留展开状态，立绘和个性语录延续原有样式。
4. 修正生化卡牌页遮挡 Wiki 背景的问题，统一标题栏与页签背景衔接。
5. 修复 Wiki 页面快速进入、返回及取消返回手势时的转场状态冲突，避免旧页面回调干扰当前导航。

## 最终交付边界

- [掉落查询](../extraction-mode-implementation.md)：新表独立按需请求及缓存。真实快照为 52 个容器、249 品质组、426 名称／品质记录；17 张来源卡可按明确容器编号关联，另外 34 张只有掉落组编号，保留完整表浏览入口。没有推算物品 ID、概率或刷取排名。工坊和图片索引未纳入。
- [角色展示](../character-detail-presentation.md)：保留紧凑顶栏、技能前移／独立 lazy／展开保存；遵从用户反馈恢复满宽 440dp、原裁切位置与渐隐，语录恢复原引号样式。
- [背景巡检及工具回退](../tools-mesh-tab-surfaces.md)：生化透明 Scaffold，标题/Tab 共用半透明底板；角色/武器/誓约背景显式对齐。工具页全部视觉改动撤销，工具子页与原版无内容差异，仅协调器调用有兼容更新。没有给工具或角色增加 Mesh；关于页仍用原效果，渲染实现已提取为公共组件。
- [Hub 转场](../hub-transition-stability.md)：统一动画收尾所有权，手势票据防止过期取消/提交，栈深度决定转场方向，退出页面回调不能重新入栈。设置/工具页同步使用共用协调器。
- 下载站仅安装包与版本元数据更新；无 Worker 业务、依赖、数据库或 WebView/Cookie/文件选择链路变更。历史版本保留。

## 本次复审及修复

- 新容器表原先只在总数声明存在时校验，缺少或重复声明可能绕过完整性检查。现要求唯一、有效的声明，并核对实际记录数；新增缺失／歧义回归。
- 明确发布的 0 项容器池与未公布池原先都显示“未公布”。现根据是否存在明确容器编号区分，新增空池回归；不把空投 `—` 推导成零出货。
- 返回手势可在标题栏点击已经出栈、但 composition 尚未更新的窗口提交。Hub 提交前再次核对栈顶路由及深度，避免重复出栈；handler 入口再次检查 enabled，onStart 纳入 finally 保护。
- 复核了缓存校验／离线回退、按需加载、搜索和品质身份、弹层与草稿归属、旧缓存兼容、动画取消/禁用/重置、共享元素边界、工具视觉回退及所有版本字段。
