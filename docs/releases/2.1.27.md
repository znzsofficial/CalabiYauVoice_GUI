## 本次复审及修复

- 新容器表原先只在总数声明存在时校验，缺少或重复声明可能绕过完整性检查。现要求唯一、有效的声明，并核对实际记录数；新增缺失／歧义回归。
- 明确发布的 0 项容器池与未公布池原先都显示“未公布”。现根据是否存在明确容器编号区分，新增空池回归；不把空投 `—` 推导成零出货。
- 返回手势可在标题栏点击已经出栈、但 composition 尚未更新的窗口提交。Hub 提交前再次核对栈顶路由及深度，避免重复出栈；handler 入口再次检查 enabled，onStart 纳入 finally 保护。
- 复核了缓存校验／离线回退、按需加载、搜索和品质身份、弹层与草稿归属、旧缓存兼容、动画取消/禁用/重置、共享元素边界、工具视觉回退及所有版本字段。
