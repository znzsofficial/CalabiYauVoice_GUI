# 2.3.2（69）发布记录

2026-11-28，上一版为 [2.3.1（68）](2.3.1.md)。本次分发 Android 签名 APK；Windows 只同步源码包版本。下载站与应用内共用[更新清单](../../downloadPage/downloads/latest.json)。本版未改 Worker 或数据库结构，无 D1 迁移。

## 玩家可见的变化

- **弦溯**：专题新增「阵列芯元」攻略入口；物资图鉴支持用品质搭配七种材料标签查升级材料。模式介绍采用新版五章，多项奖励与前置条件分行，残缺资料不会覆盖完整缓存。[弦溯专题与快照验证](../extraction-mode-implementation.md)
- **超弦体天赋**：兼容新版四组图文卡片和旧表格缓存。打开直接到分组，每项显示解锁、满级与逐级效果。[天赋解析与缓存](../android-wiki-ui-architecture.md#超弦体天赋)
- **卡牌与数据页**：生化在配卡和选卡时显示品质张数和达标差额；超弦推进将筛选收进弹层。平衡数据的统计范围可换行，点排序指标打开菜单，升降序独立切换。PC 游戏设置统一默认值、推荐和参考数据的布局。[Android 视觉规范](../android-ui-design-guide.md)
- **武器详情**：加载与正文的图片展台位置对齐，伤害表使用等宽数字。共享转场仍按[真机清单](../device-acceptance.md#23269玩法资料与界面待验)验证。
