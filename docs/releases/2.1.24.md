- **武器**：完整分类巡检 42 页（10 战术／25 主武器／4 副武器／3 近战）。效果与介绍分离，模板／HTML 两路径校验；换弹／散布／后坐力参考区保留 AI 分析等来源警告，缺失单位不推算；基础伤害、移动端和模式变体不混用。
- **生化卡组页**：明确 cardId 与同阵营选图；PC 图鉴补齐分享卡表缺卡；Base64、版本头、阵营和位图严格校验，未知索引不静默略过。无分享码属于正常状态。含未索引卡时只有明确同意才能发布完整卡牌列表，且不写 Widget 或调试码。
- **页面状态**：SaveableStateHolder 只保存轻量状态，页面／WebView 仍释放；切回恢复，明确重选首页才重置。宽窄屏读取新回调；抽屉旧跳转不能覆盖新快捷方式／返回。玻璃按需采样，旧系统回退普通底色；立绘按可见范围有限预取，取消后释放 inflight。
- **平衡／关于／网页**：筛选草稿原子应用、刷新保留条件；文字保护和生命周期／动画缩放观察；网页元数据 miss 串行，实际请求结束后间隔 6.5 秒，429／567 冷却，文件 CDN 下载不受该队列限制。

## 兼容性与仍有的限制

- Android 最低 API 25，不使用 API 26 才提供的 java.util.Base64；版本字段 Android／Desktop／设置与关于 fallback／latest.json 一起更新。
- **“盗取”20351047 在 2026-11-02 的官方分享表中没有 index**。卡池已补全，但不能声称已能生成带它的游戏导入码。需要等上游卡表补齐；不会猜测 Lua 键 80219 或 bit 位置。
- 武器细项参考不等于官方实测；保留原页警告。未来 Wiki 改版仍可能要求更新解析器。
- 下载站限流是 search 客户端实例级，不跨标签页／用户，不等于 Worker 全局限流或永不遇到 WAF。
- 无连接 Android 设备／可用 AVD。未真机确认短屏、大字体、折叠屏、TalkBack、动画设置切换、卡组发布及游戏导入，也没有帧率提升百分比承诺。
- 回归以本地桩和已捕获完整快照为主；可选跳过不作为 live passes；没有为了验收修改 Wiki、账号或生产数据库。
