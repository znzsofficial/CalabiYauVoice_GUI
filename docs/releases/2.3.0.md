# 2.3.0（67）发布记录

上一版：[2.2.5（66）](2.2.5.md)。本次分发 Android 签名 APK；Windows 源码中的包版本同步为 2.3.0。下载站和应用内更新共用[更新日志](../../downloadPage/downloads/latest.json)。

## 玩家可见的变化

- **找资料**：Hub 和普通图鉴使用「柔光画册」布局，保留展开透明的壁纸大标题、角色阵营渐变和地图图片转场。首页只显示「弦溯战线」专题入口，进入专题后再选「按物品／按来源」。地图预览和一览都支持搜索模式，普通手机双列展示，大字号优先读全名称。
- **查掉落和装备**：弦溯查询、图鉴与工坊采用「战术情报」布局，用图片、品质标签和对齐的数值区分来源与装备档位。修复来源卡漏图、物资／配件加载时品质标记换边；首次按来源搜索不再在主线程建立全量索引。候选名单不等于掉率，未公布不等于零。
- **外观与阅读**：设置第一项可换壁纸、进入预览和保存；自定义主题色能重新编辑，纯白不再被当成「跟随壁纸」。普通图鉴缩短筛选区，详情里的短说明不多放「展开」；长图缩放、边缘翻页和亮图上的操作按钮得到修正。PC 游戏设置的关键词搜索兼容复制来的全角和不间断空格。
- **更新与存储**：设置首页可直接检查更新。手动与启动检查共用结果，配置重建保留已显示的更新提示；取消系统安装可复用原 APK 重试。资源下载的分类扫描可就地重试。不可读目录不再误显为空，部分统计会标明，历史文件数不重复显示。
- **首页性能**：宽度断点在列表外统一计算；单列卡片不额外测等高，图片行停止滑动且可见时才预取。非壁纸主题不为首页预取设置色样，需要取色时在后台量化。未以关闭玻璃或降低画质换取性能。
