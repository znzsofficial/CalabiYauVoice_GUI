# 2.2.3（64）发布记录

日期：2026-11-21。相较 [2.2.2（63）](2.2.2.md)，本版适配 11 月 21 日的 Wiki 资料，并更新 Android 的字幕导出、品质筛选和攻守切换控件。

## 更新内容

- **伏闪**：点开武器机制即可放大单发开火时间轴。爆破增幅按核心、输出、续航、机能四组显示，共八项；基础参数不混入升级值或 Wiki 注释中的未公开数值。五位使用者可按角色分别跳转。[武器详情与数据来源](../weapon-parsing-audit.md)
- **弦溯战线**：恢复掉落图鉴、容器清单和按物品反查。新版收录 52 个容器，空投列出 347 项候选，散点尚未完整公布件数；六个首领阶段保留各自的品质占比。搜索来源不再匹配无关分区导语，共用名单不作来源掉率排名。缺整池、缺来源或数量矛盾时保留上一次完整资料。[弦溯图鉴专题](../extraction-mode-implementation.md)
- **新人指南**：新版八章完整展示装备说明、设置建议和 Wiki 作者问答，仍支持旧版四章离线缓存。同一文章使用不同的 Wiki 阅读链接也能识别。[指南与缓存兼容](../beginner-guide.md)
- **工具与筛选**：字幕导出按钮直接显示当前格式，右侧箭头切换格式，主按钮打开导出确认。掉落品质改用带勾选的单选菜单；平衡数据的攻守按钮互斥，仅切换本地视角。

## 验证范围

- 指南与弦溯修复后，122 项专项通过，无跳过；该阶段 Android Lint 为 0 错误、5 个既有警告。覆盖两份四章历史指南、新版八章指南、整池丢失以及空投与散点的区别。[快照入口](../live-wiki-tests.md)
- 最终三个控件替换后 Android Debug 编译通过；伏闪最新详情使用真实修订 `120510` 核对，单项通过且未跳过。缩放手势、大字号和返回体验留在[设备验收](../device-acceptance.md)。
- Android 构建依赖同步至 AGP 9.5.2、Lifecycle Compose 2.11.1、Material 3 及 Window Size Class 1.5.0。Desktop 同步包版本，本次交付 Android APK；无需数据库迁移。
