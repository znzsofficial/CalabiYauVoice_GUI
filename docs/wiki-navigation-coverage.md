三档定义：

- **原生入口**：已有业务页面，可经首页、聚合页或现有页面内的标签 / 详情进入。可只覆盖来源页的一部分，须注明；不等于将网页全部交互原样移植。
- **仅网页可达**：没有对应的完整原生业务页，仍可经 **首页 → 完整导航 → 同名菜单路径** 打开网页；部分还在聚合页有网页直达入口。外部站点也归此档。
- **缺失**：原生、聚合网页、完整导航均没有可证实入口。本次菜单范围内未证实此档。缺原生实现或缺首页搜索索引，均不能直接写成完全不可达。

完整导航自身是原生目录 UI，但其叶子调用 `onOpenWikiUrl`，不算叶子业务原生化。`NavigationMenuRemoteSource` 读取 `allmessages/sidebar`，`NavigationMenuParsers` 保留首页 / 角色 / 武器 / 地图 / 玩法 / 其他六区及子级；与这批 HTML 的顶层结构一致。本次没有重新请求 sidebar API，网页可达指代码与菜单证据支持的入口路径，不承诺实时服务器状态。

1. **移动端晶源感染卡牌**已有 `BioMobileCards` 路由与 `BioCardScreen(initialTab = 1)`，但此前搜索的「移动端卡牌」指向默认 PC 页，聚合页也没有对应入口。增加独立移动端搜索项，并加入「玩法与养成 → 移动端内容 → 晶源感染卡牌」，复用现有路由 / codec / 业务页。
2. **Wiki 原名搜索漏项**：补充角色筛选、武器筛选、角色时装投票、角色时装筛选、武器外观筛选、功能道具图鉴PC端 / 移动端、PC端晶源感染卡牌、晶源感染卡组分享、往期活动 / 公告、角色平衡数据、超弦推进模式、极限推进模式载具外观等精确关键词。「超弦体设定」引导至角色列表，具体内容仍在各角色详情的设定补充中。
3. 保留既有「游戏延伸 → 实用指南 → 游戏设置（PC） / 游戏Tips」、「玩家装饰 → 身份展示 → 个性名片」、「玩家装饰 → 外观扩展 → 休息室手办」及全部装饰屏幕 `isActive` 保护。

本次未发现有充分离线证据可断定的失效聚合 URL。菜单未出现的旧地图名不能仅凭菜单差异判死链；没有进行这样的删除。没有新增大功能，也没有将所有网页条目塞入首页搜索。

## 有证据的后续候选（均不是完全不可达）

- **玩法与养成**：晶源战备、信用分、自定义玩法共享。已有明确公共菜单叶子，但没有对应业务原生页。先评估内容结构 / 使用频率，再决定原生化或聚合网页快捷入口。
- **移动端内容**：战斗模式移动端、印迹移动端。必须按独立来源与平台边界评估，不能简单复用 PC 解析结果。
- **武器资料**：主武器理论数据表。建议位于武器入口附近的进阶资料，不把现有单武器详情当作表格实现。
- **游戏延伸**：相关周边、兑换码、人气投票、赛事活动。分别属于资料 / 实用信息 / 社区 / 赛事；不复用角色时装投票、游戏历史等不等价页面冒充覆盖。

- **首页工具箱**：反馈版及外部 / Widget 工具保持完整导航可达即可；没有证据要求全部升级为首页卡片或原生屏幕。
