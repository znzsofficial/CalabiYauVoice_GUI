# Android 架构二次复审修复

审查基线 `5b0b6ee`（2.2.1）。本页记录基线之后的源码维护；线上版本见[发布记录](README.md#发布记录)。

## Android 入口与持久状态

- **头像（A1）：** 头像解码按长边和总像素双重采样，读取本地或云端 URI 使用 IO 线程。裁切直接绘制到最多 512px 的方形结果，WEBP 压缩不在 UI 线程。页面取消后不发布旧预览。
- **快捷方式（A2）：** 从抽屉、登录入口或快捷方式进入 Wiki 浏览器，都保留上一个非浏览器目的地。重复进入不把 Wiki 自己设为返回目标。
- **更新下载（A3/T7）：** 启动提示与设置页共用系统下载记录。用带构建指纹的 URL 和目标版本识别任务，重开时接管暂停任务或显示已下载的安装包；新任务不删除同名旧文件。UI 只在前台跟踪进度；记录持续不存在时结束等待并允许重试。
- **HTTP 读取（A4）：** `Call.awaitResponseText()` 保留响应状态、头和业务错误正文，取消绑定持续到正文读完并关闭响应。留言、身份、档案、通知及点赞查询使用该入口；业务写入的重试策略另由各功能负责。
- **崩溃报告（A5）：** 主进程把长度有上限的报告写入私有目录，Intent 与保存状态只传记录 ID。独立报告进程可按同一 ID 重开；旧版待处理记录迁移一次。
- **留言删除（A6）：** 首页列表在请求开始时预约磁盘写入。确认删除后废止旧写入并使首屏磁盘副本失效；紧接的刷新即使断网，退出重进也不会从旧首屏恢复已删主留言或其置顶副本。

## Wiki 写入、缓存和导航

- **投票与卡组（W1/W2）：** 提交前核对候选项、投票 ID、总计项和正数票数上限；有问题文本时核对其身份。数据缺项、重号或身份冲突时禁止提交。获取 token 及每次写入都检查当前 Job 和原账号会话。投票、发布成功或待审核须有明确回执，已经发出的写入不能靠取消撤回或自动重放。
- **磁盘与内存（W3–W5）：** 角色、武器及公告在发布前校验业务结构。合法空公告仍是成功；结构不对时保留可用副本。武器详情、武器分类和卡组索引保留依赖的离线状态，不把回退值变成永久在线命中。清理前排队的强刷和立绘派生写入不能取得清理后的发布权。
- **展示、搜索和返回（W6/W7/W10）：** 网络成功优先于磁盘预取，包括空结果；网络失败可显示旧资料及刷新错误。地图页可主动验证，有完整名单时搜索不再补入固定旧地图。武器跳回已有使用者角色前检查当前栈顶，转场迟到的旧回调不能截掉新页面。
- **壁纸与平衡数据（W8/W9）：** 启动、Hub、设置页的壁纸选择共用发布顺序，旧自动结果不能覆盖后来的手动选择；设置区分已更换与沿用旧图。离开平衡页或切换查询会取消实际 HTTP 正文读取。

## 下载与媒体工具

- **名称、目录和任务所有权（T1/T2/T6）：** 资源下载把完整清单的名称都视为已占用，即使文件未写出或已移走。对旧清单重复归属，优先保留与磁盘长度及哈希匹配的记录。重启只清理有私有记录的下载暂存件；Android 与 Desktop 适配器都执行该约定。工具中的文件管理根始终是保存根，初始浏览位置单独校验。音频编辑使用独立工作目录，不清理借用的原文件。
- **发布成品（T3/T4/T12）：** EXIF 先在应用私有暂存文件上清理并读回所列隐私标签，再发布副本。视频封装必须成功结束；拆轨先完成两轨，运行时后续发布失败会回滚本批已发布文件。截图检查编码返回值，音频及字幕导出也走输出事务，只报告实际发布路径。多文件发布不是跨进程死亡的原子操作。
- **编辑历史与任务退出（T5/T11）：** 音频候选节点复制、回读成功后才替换历史和预览，导入失败或编辑失败保留原可导出的版本及重做分支。频谱重绘替换旧任务，计算与拷轨循环检查取消，退出音频工具只释放本页拥有的播放。
- **文件格式（T8–T10）：** GIF 每个图像描述符有独立帧状态，无控制块时不会重复上一帧；读取前校验输入字节数、画布与帧矩形，编码明确限制 16 位尺寸。WAV 对奇数 PCM 数据长度写 RIFF 对齐填充，数据块长度不含填充。
