# 超弦体详情展示优化

2026-11-06，纳入 [2.1.27（57）](releases/2.1.27.md)，以发布记录为最终交付状态。下文保留 UI 迭代与阶段验证记录。

## 视觉与阅读顺序

- 顶栏改为紧凑固定栏，角色身份放在立绘下方，减少双重大标题占据首屏。
- 根据用户视觉反馈，立绘恢复原来的满宽 440dp、Crop 和偏上对齐（BiasAlignment 0 / -0.85），底部 60dp 渐隐衔接页面背景；无边距、无圆角舞台。头像保持 240dp，图片请求失败显示中性占位，无图片地址时不占据头图空间。
- 用户反馈语录 Mesh 装饰不合适，已移除角色页全部 Mesh；个性语录恢复原 28dp 引号图标和半透明 secondaryContainer 卡片。
- 技能提前到语录之后，先呈现可操作的战斗信息，再展示人物介绍与设定。每个技能为独立 lazy item，展开状态提升到内容层并可保存，不随列表项回收丢失。
- 技能标题增加槽位标签和展开语义，点击区域至少 56dp；展开内容取消左侧图标缩进，给小屏与大字体保留完整正文宽度。
- 加载态复用原尺寸的立绘展示，语录占位同步恢复 28dp，技能占位跟随新的内容顺序。

## Mesh 复用与生命周期

`core/ui/ThemeMeshBackdrop.kt` 从关于页实现提取，仍使用 Compose `MeshGradientPainter` 的 3×3 网格、双三次颜色插值和绘制阶段 State 读取；没有添加依赖。关于页保留轻量适配入口及既有回归入口。

- 动画只在 Activity RESUMED 且系统动画倍率有效、非零时运行。
- 角色页不再调用 Mesh；工具页也按用户要求回退，共用实现目前仅供关于页使用。
- 关闭系统动画、切后台后移除无限 transition；重新进入前台重新读取系统设置。
- 图像共享过渡仅附着在图像上，不把 Mesh 和文字一起拉伸。

## 验证边界

实现阶段与掉落查询合并验证：Android 423 项，11 项可选跳过，0 failures/errors，关于页既有 Mesh 回归通过；当时未配置武器与地图卡池外部快照。最终 2.1.27 发布检查已包含这些快照：Android 433 项／9 可选跳过／0 失败，Lint 0 errors／5 个既有 warnings。完整结果以 [发布记录](releases/2.1.27.md) 为准，阶段数量不代表当前总数。

当前 `adb devices` 没有设备，尚未进行真机截图、大字体、共享过渡或帧耗时验收。

## 2.1.29：超弦体设定解析与缓存（2026-11-12）

纳入 [2.1.29（59）](releases/2.1.29.md)，最终发布状态以发布记录为准。

角色详情的“设定补充”读取 [超弦体设定](https://wiki.biligame.com/klbq/超弦体设定)，不是从单个角色页复制。角色主字段、技能与立绘仍来自各角色页面。网页导航只链接该设定页，没有另一套字段解析。

### 解析

- 从 `CharacterDetailApi` 分离 `CharacterSettingsParser`、`CharacterSettingInfo` 和 `CharacterSettingsApi`。继续使用原 `CHARACTER_DETAIL/character_setting` 原始响应缓存，旧缓存也按新逻辑解析。
- 当日完整页面为 24 个 `.klbq-role-info`，每个包含 12 个定义字段：萌点、生日、星座、年龄、身高、体重、活动区域、兴趣爱好、饮食习惯、个性语录、简介、观测语录。移除旧代码对“萌点”的过滤；未知新字段也保留源标签。简介、观测语录分开显示，其余进入生活信息。
- 兼容 `dl > div > dt/dd` 与直接相邻 `dt/dd`、多个 `dd`；保留换行、链接文字和黑幕／彩幕中的文字，去掉 CSS、脚本、引用标记与 tooltip 辅助内容。不同值的同名字段不会静默覆盖。
- 关系字段按 `.data` 容器读取一次，支持中英文冒号，不依赖 `p/span` 包装；嵌套 span 不再重复关系。中文／日文 CV 留在主资料，不当人物关系。
- 姓名优先取明确正文链接，再取姓名元素自身中文；不会把英文日文附注拼入角色名。中点和空白统一，奥黛丽／玛德蕾娜／加拉蒂亚使用已核对的全名别名表，不做任意前缀匹配。
- 完全相同的重复角色块可去重；同身份冲突、缺失姓名、孤立 dd、缺失简介／观测语录定义或无有效字段会拒绝缓存，保留最后有效磁盘副本。简介／观测语录值可以显式留空；数量不硬编码为 24。页面完整删除某块无法仅靠结构校验检测，不宣称具备服务端总数校验。
- 与主页面完全相同的生日等字段以及简介／观测语录继续去重；不同值保留在标明来源的补充卡，不覆盖角色主字段。

### 加载与缓存

- 设定页失败不再产生永久的空内存缓存；错误作为 `settingLoadError` 显示，主角色资料仍可读，用户可用顶部刷新重试。
- 设定页离线结果保留年龄，合并后的详情如使用任一离线来源，也返回离线标记与最大年龄；离线或缺设定的详情不写永久内存缓存。
- 设定缓存与角色详情均使用请求版本保护，清理缓存使进行中的旧写入失效。详情内存记录绑定设定快照；任意角色刷新成功替换设定快照后，其他角色旧详情不会继续命中过时补充设定。
- 当整页成功且没有某个角色（例如晶源体），按未收录处理，不猜关联；未知角色不套用相似名字。

### 验证

- 已获取 2026-11-12 真实网页，保存于本机 `character-settings-20261112/settings.html`；`CHARACTER_SETTINGS_AUDIT_FILE` 指向该文件时，逐角色逐字段验证 24 × 12 项，含当前萌点内容。普通网页抓取成功不代表此前被 567 拦截的其它 API 已恢复。
- 小型 fixture：`androidApp/src/test/resources/fixtures/character/settings.html`；8 项设定解析／缓存测试加既有缓存回归，共 **29 项，0 失败／0 跳过**。没有在测试中逐角色联网。
- Android 编译、Lint 通过（0 errors / 7 warnings：2 AGP 版本提示、1 ModifierParameter、4 UseKtx）。提交与发版见 2.1.29 发布记录；尚无本轮真机视觉验收证据。
