# 超弦体详情展示优化

2026-11-06，纳入 [2.1.27（57）](releases/2.1.27.md)，以发布记录为最终交付状态。下文保留 UI 迭代与阶段验证记录。

## 视觉与阅读顺序

- 顶栏改为紧凑固定栏，角色身份放在立绘下方，减少双重大标题占据首屏。
- 根据用户视觉反馈，立绘恢复原来的满宽 440dp、Crop 和偏上对齐（BiasAlignment 0 / -0.85），底部 60dp 渐隐衔接页面背景；无边距、无圆角舞台。头像保持 240dp，图片请求失败显示中性占位，无图片地址时不占据头图空间。
- 用户反馈语录 Mesh 装饰不合适，已移除角色页全部 Mesh；个性语录恢复原 28dp 引号图标和半透明 secondaryContainer 卡片。
- 技能提前到语录之后，先呈现可操作的战斗信息，再展示人物介绍与设定。每个技能为独立 lazy item，展开状态提升到内容层并可保存，不随列表项回收丢失。
- 技能标题增加槽位标签和展开语义，点击区域至少 56dp；展开内容取消左侧图标缩进，给小屏与大字体保留完整正文宽度。
- 加载态复用原尺寸的立绘展示，语录占位同步恢复 28dp，技能占位跟随新的内容顺序。

## Mesh 复用与生命周期

`core/ui/ThemeMeshBackdrop.kt` 从关于页实现提取，仍使用 Compose `MeshGradientPainter` 的 3×3 网格、双三次颜色插值和绘制阶段 State 读取；没有添加依赖。关于页保留轻量适配入口及既有回归入口。

- 动画只在 Activity RESUMED 且系统动画倍率有效、非零时运行。
- 角色页不再调用 Mesh；工具页也按用户要求回退，共用实现目前仅供关于页使用。
- 关闭系统动画、切后台后移除无限 transition；重新进入前台重新读取系统设置。
- 图像共享过渡仅附着在图像上，不把 Mesh 和文字一起拉伸。
