# 2026-11-22 交接：2.2.5 发布后的 Android 改动

**阶段交接归档。** 本文记录 [2.2.5（66）](../releases/2.2.5.md) 发布后、准备 2.3.0 前多个阶段的工作与验证；当时 `master` 与 `origin/master` 同为 `554cbd0`。最终交互以[设计规范](../android-ui-design-guide.md)为准，当前版本和产物以[发布记录](../releases/README.md)为准。

## 本地已经改好

- **Wiki 首页**：恢复可折叠大标题、角色阵营色和地图渐变；「完整导航」回到页尾。弦溯专题接入液态玻璃。遮罩随滚动绘制，地图共享转场只移动图片。搜索清空后旧结果不能再跳转；返回列表后，已退出的角色／地图详情不能再打开网页。见[首页与导航](../android-navigation-followup.md#主导航及首页)。
- **设置与更新**：「检查更新」移至设置首页「应用」，与「关于」分开。启动检查和手动检查共用结果；配置重建保留已显示的提示，安装器返回前不重复发起安装。目录选择只修改草稿；存储统计一次遍历，壁纸保存失败或取消时保留旧文件。见[设置与关于](../android-navigation-followup.md#设置与关于)、[文件管理](../android-core-file-manager.md#文件管理)。
- **弦溯查询**：修复只看首个匹配品质导致来源卡丢图的问题。按来源搜索首次输入不再同步建立全量索引；已选分类先返回结果，后台索引只服务当前快照。核对名单、品质和目标，不把共用池的排名当作掉率。见[弦溯专题](../extraction-mode-implementation.md)。
- **阅读与图片预览**：骨架高光只在绘制阶段读取进度；PC 设置的普通、全角和不间断空格使用相同的搜索规则。已有内容刷新失败时只保留一个重试入口。超宽图和长图按实际图幅限制平移，不能再平移的方向交回翻页；系统栏区域不被放大的图片覆盖。见[公共 UI](../android-wiki-ui-architecture.md)、[PC 设置](../pc-game-settings.md)。
- **后续复查**：弦溯目录的玻璃分组和查询按钮按实际文字色保护对比度，壁纸未就绪时录制主题底色。2.2.5 已有的下载目录读取失败误显 `0 B` 也已在本地修复：根目录失败显示无法读取，部分失败保留已知值并可重试，真实空目录仍显示零。
- **Hub 布局**：首页将预览标题、操作与预览内容归入同一卡片，「更多资料」合并为四行自适应目录；地图模式提供可搜索的选择列表。弦溯目录保留三个玻璃分组，宽屏下两组资料并排，窄屏原文标记可换行。Debug 层的 `HubLayoutPreviews.kt` 提供窄屏大字号、宽屏深色两种离线预览入口。

## 验证边界

Hub 首页减少滚动时的重复布局并将壁纸取色移出主线程后，用户反馈「性能看起来不错了」。这是本轮体验反馈，未记录设备帧耗时，不作为所有机型的帧率结论。

另一次应用端复查已修复下载分类重试、设置开关语义、地图错误类型和长名称、弦溯两种入口的资料状态，以及道具详情的恢复与刷新。关于界面层级和控件样式的问题单列在[原生页面设计复查](2026-11-22-android-visual-review.md)。

这六项改动的 Android Debug 编译通过，10 项针对性 JVM 用例全部通过。另用原生静态预览核对：地图首开 `NOT_FOUND` 显示「未找到数据」，双列、2 倍字号的「科斯玛能源中心」可换行读全。TalkBack 实际播报、应用重建与返回手势留待设备核对。

- 首轮回归修复分两批运行 Android Debug 定向检查：**36 + 10 = 46 项，均无失败、无跳过**。覆盖搜索、图片平移、离线副本、导航、更新请求接管、配置重建及安装去重等路径。较早的性能巡检 38 项、设置调整 6 项与这些有重叠，不累加。
- 后续针对玻璃与 `0 B` 单独运行 `WikiWallpaperInkTest`（3 项）和 `DownloadStorageScanTest`（4 项），Debug 编译通过，7 项无失败、无跳过。默认深浅主题在测试壁纸色块上的文字合成对比度达到 4.5:1；存储使用临时目录并注入权限失败来核对已知用量。两者都是 JVM 检查，未验收设备折射或 Android 存储权限。
- Hub 布局打磨使用已编译的 Debug 组件，经 Compose Preview renderer 与 Android Studio Layoutlib 渲染了四张原生静态预览：首页资料区和弦溯目录各有 320dp／1.5 倍字号浅色、600dp／默认字号深色两种。核对了目录单双列、查询按钮排列、长标签与原文标记。地图筛选、快捷配置、文字对比、预览可见性和弦溯路由等 23 项定向用例实际通过（首次 22 项通过、1 项跳过；用 11 月 21 日快照单独补跑通过）。预览使用普通主题表面，不作设备壁纸折射或返回动画的验收证据。
- 玻璃二次复查覆盖首页与实际读取背景的五个二级目录。搜索、独立快捷按钮和普通目录卡补用文字衬底；无壁纸时改采纯色，不再录制整屏。`WikiWallpaperInkTest` 与 `HubTransitionTargetTest` 合计 7 项通过；其中默认深浅主题下测试的文字与黑／白背景合成对比度均达 4.5:1。重新渲染上轮四种普通材质预览，逐张比对 RGBA 均为 0 个像素变化。设备模糊、折射及预测返回仍待验收。
- 离线对照三份弦溯快照：24,042 组查询与分类组合的顺序和详情目标与发布基线一致。已发布版、本地优化前后对照的是 Kotlin/JVM 结果；运行时分配量和遍历次数不是手机帧率或内存峰值。PC 设置完整快照中，普通／全角／不间断空格写法的「手柄 跳跃」均命中相同的 4 项。
- 玻璃二次复查时的完整 `:androidApp:lintDebug --offline` 为 **0 错误／5 警告**：`UsageStats.kt` 两处 `StaticFieldLeak`，`AppPrefs.kt` 三处 `UseKtx`，Hub 与玻璃实现没有报告项。这份报告早于后续的六项修复。[2.2.5 的发布结果](../releases/2.2.5.md#发布前验证)另计。
