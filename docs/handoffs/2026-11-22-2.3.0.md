# 2.3.0 发版后交接 · 2026-11-22

本页保留 **Android 2.3.0（67）** 发布当日的交接。源码 `85ec269`，签名包元数据 `bfec607`，主站核验与发布记录 `825b7d3`。11 月 24 日以后的活动、弦溯与解析兼容见 [2.3.1 发布记录](../releases/2.3.1.md)；后续版本从[文档索引](../README.md)接续。

## 哪些决定已经定下

- **找资料与查数据用不同的排版。** Hub、普通图鉴及详情采用 A「柔光画册」，让玩家先看到图片和名称；设置与弦溯采用 B「战术情报」，让玩家容易找到开关、比较品质和数值。用户认可当前设计。改 UI 先看[视觉规范](../android-ui-design-guide.md)，再看原生画面；功能 Bug 单列，不能代替视觉审查。
- **首页选栏目，专题选查法。** 首页整张「弦溯战线」卡只进专题；「按物品／按来源」留在专题里，具体搜索仍可直达。「完整导航」在页尾。首页有壁纸时，大标题展开及折叠前 8% 完全透明。地图预览与一览共用模式选择器但分别保留位置。详见[导航约定](../android-navigation-followup.md#主导航及首页)。
- **高频设置少走一层。** 壁纸是设置首页第一项，可直接换图；检查更新独立于关于页。取消安装保留 APK；下载目录读不到不等于 `0 B`。这两项已修，不是待实现功能。
- **首页性能以已认可的画面为基线。** 已减少重复布局和立绘坐标状态写入，加载占位共用时钟，壁纸色样按需在后台计算。用户反馈流畅度改善；没有设备帧耗时数据，不写提升百分比。

## 证据与未验范围

[发布记录](../releases/2.3.0.md)是最终验证口径：713 项 Android JVM 用例中 681 项通过、32 项可选跳过、0 失败；完整 Lint 为 0 错误、5 个既有警告。主域名的版本、7 条更新日志、下载地址及 APK 长度均已核对。此前的定向用例、快照和原生预览用于定位具体问题，不与最终数字累加。阶段性方案可追溯到[开发交接](2026-11-22-post-2.2.5.md)和[视觉复查](2026-11-22-android-visual-review.md)，两者不是当前布局规范。

有设备时优先走两条路径：**下载更新时更改系统字号 → 取消安装 → 再次安装**；**保存壁纸到 Pictures → 确认文件可打开**。其余玻璃折射、共享转场、长图边缘翻页和 TalkBack 操作见[设备验收清单](../device-acceptance.md)。静态预览与用户的流畅度反馈不替代这些实测；暂无新一轮改版或继续调优的排期。
