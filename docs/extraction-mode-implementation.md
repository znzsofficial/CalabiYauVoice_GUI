本专题纳入 **2.1.24（54）**，仅 Android 原生客户端；未接入仍在建设的其它系统。最终发布状态与校验以 [2.1.24 发布记录](releases/2.1.24.md) 为准。

2026-11-04 架构与新版掉落页适配纳入 [2.1.26（56）](releases/2.1.26.md)，最终交付状态以其发布记录为准。下方测试记录保留各阶段观测。

## 入口与范围

- “战斗模式”新增 **弦溯战线**，读取现有 Wiki 简介和模式设定；当前简介是四张教学图的说明文字，提取文字而不是把导航模板当简介。
- **外观与图鉴 → 弦溯战线** 下有 **战利品图鉴、配件图鉴、掉落图鉴** 三个原生入口；战斗模式仅保留简介与设定，不再承载图鉴导航。首页搜索也能按“弦溯战线／搜打撤／配件图鉴／掉落图鉴”等找到。
- 维里昂裂隙从模式页面解析名称；后续已核对页面并接入原生地图列表及详情，显示简介、平台、概览图和地形图。没有虚构尚缺的图集或历史；详见 [地图与卡池后续](rift-bio-pool-followup.md)。
- 当前模式没有独立“获胜条件”段落时留空，不生成推测内容。

## 三个图鉴

所有解析都基于 `action=parse&page=<page>&prop=text` 返回的渲染 HTML，不依赖客户端执行 Lua、Widget 或页面 JavaScript。

| 图鉴 | 源页面 | 当日完整快照结果 |
| --- | --- | --- |
| 战利品 | `战斗模式/弦溯战线/物品图鉴` | 159 条 |
| 配件 | `战斗模式/弦溯战线/配件图鉴` | 127 条 |
| 掉落 | `战斗模式/弦溯战线/掉落图鉴` | 53 张唯一掉落卡 + 51 条完整掉落池记录 |

条目数量只是 2026-11-02 的观测结果，应用不以数量作硬编码限制。

- 战利品：名称、分类、稀有度、图片、描述、价值、占格、重量、售价、搜刮时间、叠加上限、使用效果、出现率／常见来源、标签。支持搜索、分类、稀有度、贵重标签和数据排序。
- 配件：上述共用字段，以及 **实际效果** 和 **适用武器／弹药**；槽位单独筛选。数据没有出现率时不提供伪造的出现率排序。
- 掉落：普通／精英晶源体、Boss、Boss 阶段与场景容器分区；必掉物、池内最高权重、池构成、掉落件数分布、池规模、出现方式、完整池列表。可以按掉落物名称搜索来源。
- 掉落页当时完整重复了一遍卡片内容：去掉完全相同的副本，保留同名但阶段／档次／数据不同的条目；总览表完整池内容单独保留，不拿高权重前三项冒充完整池。
- **概率不自行换算**：“池内最高权重”、“件数概率”和战利品“出现率”保留各自 Wiki 字义；详情提示不等同于单局获得概率。
- 显示值保留 Wiki 格式，例如搜刮 `0.17s`。`data-sort-time=170` 仅用作排序，不将它直接显示成 170 秒。
- 本模式稀有度 `1=优秀，5=臻藏`，不套用其它图鉴的 `初始／传说` 文案；掉落卡的 `data-tier` 表示难度，不映射为物品稀有度。

## 实现边界

新增包 `feature/wiki/extraction/`，按 `model / parser / source / api / Screen` 分层。三个 catalog kind 集中管理页面名和版本化缓存 key，均以 `extraction_` 开头，不复用 PC／移动端道具缓存。

- 图鉴采用全页单次请求，图片直接取页面 URL，并处理缩略图／原图和 lazy src/srcset，不逐项请求 imageinfo。
- 仅进入相应图鉴才加载那一页，不进模式页就并发拉三个图鉴。
- 磁盘和内存缓存按图鉴隔离，强刷绕过内存；网络回退带离线年龄。
- 保存前验证 MediaWiki payload 和对应图鉴结构；空建设页、WAF、错误图鉴响应不能覆盖最后的有效磁盘副本。取消继续抛出，不变成“空图鉴”。
- 搜索和筛选在客户端进行，不产生额外网络请求。筛选弹层及详情使用有界 LazyColumn，避免固定顶部筛选挤压列表；长完整池可以滚动。
- `ExtractionCatalogSkeletons.kt` 提供专用加载布局：战利品／配件是与内容一致的 120dp 自适应图片网格、稀有度角标和双行名称；掉落为无图片的文本列表卡片，包含分类、掉落摘要与概率提示的占位。三页不再套用带内联分类下拉、稀有度 chips 的通用道具骨架，筛选仍在弹层。
- 默认排序保留源码顺序；未知数值排序置末，不冒充 0；真正的 0 保留。
- 路由 `ExtractionCatalog(kind)` 有独立保存编码，未知 kind 恢复失败，不影响旧的 `items`、`mobileItems` 或 `gameModes` 路由。
