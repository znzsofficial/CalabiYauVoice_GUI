# Android 导航与页面状态

本专题的改进纳入 **2.1.24（54）**，不是 2.1.23 的行为。发布状态、最终构建与验证以 [2.1.24 发布记录](releases/2.1.24.md) 为准。

## 卡组分享

- 静态显示与导入共用严格 Base64 和 `000B|阵营|十六进制位图` 校验，兼容缺失的 Base64 填充与官方 `**` 后缀。
- **没有分享码是正常状态**：无静态码且无明确生成脚本时返回空，详情不显示分享码块/复制入口。不从卡名推测卡组码。
- 明确的官方生成脚本只在全部 cardId 已知时重建；未知卡片/索引不得静默略过后生成另一套卡组。
- 卡面按 ID 优先、同阵营同名兜底；图鉴图片索引只在图鉴变化时建立。
- 使用现有 Okio 编解码，不引入要求 API 26 的 `java.util.Base64`；最低 API 仍为 25。

## 平衡数据

- 仅保存筛选 code、攻防与排序；加载设置后校正失效 code，保留其它有效条件。
- 刷新不再清空有效筛选。
- 弹层编辑草稿，“应用筛选”才原子更新查询；取消、返回或点击遮罩放弃草稿。草稿多选不发请求，应用相同条件不重复请求。
- 弹层全宽输入框及整体滚动适配短屏、大字体；对比赛季互斥、旧赛季无表现分规则不变。

## 关于页

- 保留主题色流动网格；文字有不透明主题保护底色，低对比前景回退到满足 4.5:1 的黑/白。
- 动态观察系统动画缩放；前台恢复重新读取。关闭动画/不处于 RESUMED 时移除无限动画，保留静态网格。
- 动画值只在绘制阶段读取，不驱动整页逐帧重组。

## 主导航及首页

- 主目的地和 Hub 子路由用 SaveableStateHolder 保存轻量 UI 状态，不让所有页面常驻。WebView、请求和回调仍按组合生命周期释放。
- 从设置、下载等主目的地回 Hub 恢复原位置；在 Hub 时明确重选“首页”或收到新快捷方式仍可以重置。显式重置有新 generation，旧状态不会复活。
- 使用 updated content 消除 movableContent 捕获旧宽屏判断的问题；改变导航容器时保留内容身份。
- 抽屉关闭后才构建新目的地；连点取最后一次，新快捷方式/返回/宽窄屏切换取消旧等待跳转。
- 主目的地淡入 200ms、淡出 100ms；普通 Hub 路由入场 220ms，详情共享元素路径保留 400ms。保留预测性返回/取消行为。
- 只有实际显示（包括未跨阈值的手拖）、动画中或常驻的玻璃侧栏才录制主背景；横屏/旧系统无用录制关闭。API 31 以下 Hub 子树统一回退普通卡片底色。
- 账号同步保留原 Cookie/身份版本隔离，退后台暂停轮询。
- 首页仍保留六个自定义快捷入口，平衡数据/武器入口前置，资料预览与更多资料分区；宽屏限制内容宽度并展开快捷布局。没有新增手机底栏或替换为新的导航架构。
- 首页“快捷与常用”和“资料预览”仅显示分区标题，删除自定义/点卡片查看详情的操作式副标题；“更多资料”的副标题保留。
- 首页和角色网格只预取可见项及最多两个邻近项；滑动/离开视口取消，停下后延迟 160ms 合并。全局预取预算最多两个，成功/失败/取消都释放临时 inflight 所有权；不把成功 URL 永久标为请求中。

## 下载站搜索

- 当前 search 客户端实例内 Wiki 元数据请求串行，每次实际请求结束后间隔至少 6.5 秒，失败/取消也保留间隔。
- 新鲜缓存立即返回，不占网络额度。排队时若已由其它请求填充缓存，也直接返回；文件/CDN 下载不进入该调度器。
- timeout 从真正开始请求时计时；排队与在途均可取消。
- 识别原始/代理包装的 429、567、HTML 风控与 MediaWiki 限流，进入冷却并拒绝 fallback 追打。
- 首次全台词索引仍按需；已有缓存可补漏。索引串行构建，失败保留最后成功数据，风控后停止而不是将所有剩余角色标失败。
- 限流不跨标签页/用户，不替代 Worker 上游限流，也不代表全站不会再遇到 EdgeOne。

## 回归与设备验收

自动检查入口：

```text
.\gradlew.bat :androidApp:testDebugUnitTest :androidApp:lintDebug :shared:jvmTest :desktopApp:test --offline
downloadPage: pnpm check / pnpm test:search / pnpm test:balance / pnpm test:worker / pnpm build
```

- 解析/请求检查仅使用本地假数据；请求调度测试使用 fake clock/fetch，没有批量请求 BWiki。
- 导航使用真正的 Compose SaveableStateHolder 进行无 UI 的 JVM 回归：页面移除恢复、注册表重建、重置隔离、最新回调。测试仅为 `android.os.Trace` 的设备追踪标记提供 no-op shim，没有全局开启 Android API 默认返回。
- 子代理独立复查又发现并补上了快捷方式覆盖、手拖抽屉录制和旧系统玻璃降级边界。
- 本地没有连接 Android 设备，也没有可用 AVD。短屏/折叠尺寸变化、TalkBack、关于页逐帧视觉效果、预测返回和帧耗时仍需设备确认。未声称帧率提升比例或“完美解决”。

### 阶段验证与发布基线

- 最初导航专项阶段 Android 300 项（9 项可选测试跳过），随后增加武器、图鉴及卡池回归；不要把这个阶段数量当作完整发布数量。
- 最终 Android/shared/Desktop、Lint、网页检查和发布产物以发布记录为单一基线，避免各专题维护多份易失效的总数。
- 修复后进行了独立交叉复查；`git diff --check` 无空白错误（Windows 行尾提示除外）。

## 2.1.25：平衡页文案（2026-11-03）

- Android 筛选弹层删除草稿、取消路径、重置生效时机和重复赛季预览的解释；操作统一为“重置筛选 / 应用筛选 / 取消”，地图及段位的不限条件使用“全部”。
- 赛季对比保留所选赛季、百分点单位和表现分的 S8 起始说明，删除“数值变化不代表角色强弱”；卡片的“原”改为“对比”，避免暗示只能与更早赛季比较。空状态改为简短的筛选建议。
- 查询、草稿应用／取消、重置默认值、排序和差值计算均未改变。平衡专项 16 项测试全部通过。用户在发布前反馈其它内容已测试无问题；这是用户验收，不是代理真机检查或全设备覆盖。网页平衡看板不在本次修改范围；版本、最终回归及发布状态以 [2.1.25 发布记录](releases/2.1.25.md) 为准。
