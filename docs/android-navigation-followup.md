# Android 导航与页面状态

本页说明 Hub 缓存、原生导航和返回行为。最初改进随 [2.1.24（54）](releases/2.1.24.md) 交付；下方带日期的验证数字对应当时的版本。

## 当前行为

- Hub恢复使用完整在线列表快照，离线/不完整结果不取得跨重建免验证资格；清缓存及新请求均废止旧发布。搜索复用当前快照，不额外持有永久旧索引。
- 角色、地图、武器按路由依赖加载，下载搜索在首次进入下载页时初始化。首页必要资料仍加载，不能称为首页零网络请求。
- `LoadState`取消和错误收尾绑定请求版本；公共读请求去重支持有界owner接管。细节见[架构修复](android-architecture-fixes.md)。
- 完整导航中明确支持的文章优先原生打开；锚点、未知页和原文按钮保留网页。弦溯物资新旧标题指向同一原生路由，弦溯装备与工坊只匹配各自的确切子页，掉落表格保留原表。见[原生分流](native-mechanics-pages.md#完整导航的原生分流)和[弦溯入口](extraction-mode-implementation.md#入口与范围)。
- 前后台轮询/WebView行为见[WebView专题](android-webview-auth.md)，设备事项见[验收清单](device-acceptance.md)。

- 地图一览可主动刷新并显示离线年龄；首开失败显示数据源的实际错误类型（例如「未找到数据」），已有资料时保留列表和刷新失败原因。完整模式名单到达后搜索移除固定兜底条目。武器详情按完整姓名分别提供使用者入口；点击时检查页面身份，覆盖层存在时不改栈。
- 重复使用 Wiki 快捷方式保留上一个非浏览器页面。设置页手动换壁纸优先于此前启动的自动选择，沿用旧图不提示“已更换”。回归场景见[二次复审](android-architecture-round-two.md)。

## 卡组分享

- 静态显示与导入共用严格 Base64 和 `000B|阵营|十六进制位图` 校验，兼容缺失的 Base64 填充与官方 `**` 后缀。
- **没有分享码是正常状态**：无静态码且无明确生成脚本时返回空，详情不显示分享码块/复制入口。不从卡名推测卡组码。
- 明确的官方生成脚本只在全部 cardId 已知时重建；未知卡片/索引不得静默略过后生成另一套卡组。
- 卡面按 ID 优先、同阵营同名兜底；图鉴图片索引只在图鉴变化时建立。
- 使用现有 Okio 编解码，不引入要求 API 26 的 `java.util.Base64`；最低 API 仍为 25。

## 平衡数据

- 仅保存筛选 code、攻防与排序；加载设置后校正失效 code，保留其它有效条件。
- 刷新不再清空有效筛选。
- 弹层编辑草稿，“应用筛选”才原子更新查询；取消、返回或点击遮罩放弃草稿。草稿多选不发请求，应用相同条件不重复请求。
- 弹层全宽输入框及整体滚动适配短屏、大字体；对比赛季互斥、旧赛季无表现分规则不变。

## 设置与关于

设置首页分为「个性化」「通用」「隐私」「应用」。换壁纸是常用操作，「壁纸」作为设置首页第一项独占整行，点一次进入，返回直接到设置首页。摘要显示自动更换状态；「首页快捷入口」和「外观」排在其下，随宽度和字号切换双列／单列。「配色细节」仍返回「外观」，「存储空间」仍返回「下载与存储」；只有进入存储明细时才扫描空间。设置和 Wiki 首页共用同一快捷入口编辑器，有未保存草稿时由编辑器接管系统返回。

匿名使用统计仍可在隐私区直接切换。「应用」把「检查更新」与「关于」分开：点更新行才请求版本信息，关于页保留版本、项目介绍和链接。

设置开关整行作为一个命名的开关展示标题、说明和状态；尾部 `Switch` 仅展示状态，不再单独接收点击。

启动静默检查尚未返回时，点「检查更新」会接管同一次请求；手动检查被放弃后，旧的启动回执不会再弹第二次。已显示的新版本由 Activity 的 ViewModel 保留，配置重建不会丢提示；进程死亡后重新检查，不把下载进度作为安装依据。下载状态来自系统 DownloadManager。连续点「安装」只写一次安装记录、启动一次系统安装器；取消返回可重试，返回本身不代表安装成功。

- 保留主题色流动网格；文字有不透明主题保护底色，低对比前景回退到满足 4.5:1 的黑/白。
- 动态观察系统动画缩放；前台恢复重新读取。关闭动画/不处于 RESUMED 时移除无限动画，保留静态网格。
- 动画值只在绘制阶段读取，不驱动整页逐帧重组。

## 主导航及首页

- 主目的地和 Hub 子路由用 SaveableStateHolder 保存轻量 UI 状态，不让所有页面常驻。WebView、请求和回调仍按组合生命周期释放。
- 从设置、下载等主目的地回 Hub 恢复原位置；在 Hub 时明确重选“首页”或收到新快捷方式仍可以重置。显式重置有新 generation，旧状态不会复活。
- 使用 updated content 消除 movableContent 捕获旧宽屏判断的问题；改变导航容器时保留内容身份。
- 抽屉关闭后才构建新目的地；连点取最后一次，新快捷方式/返回/宽窄屏切换取消旧等待跳转。
- 主目的地淡入 200ms、淡出 100ms；普通 Hub 路由入场 220ms，详情共享元素路径保留 400ms。保留预测性返回/取消行为。
- 只有实际显示（包括未跨阈值的手拖）、动画中或常驻的玻璃侧栏才录制主背景；横屏/旧系统无用录制关闭。API 31 以下 Hub 子树统一回退普通卡片底色。
- 账号同步保留原 Cookie/身份版本隔离，退后台暂停轮询。
- 首页把搜索和「快捷入口」放在上方；「完整导航」在页尾，与公告、活动等入口并列，也可搜索直达。弦溯卡片只打开专题，在专题内再选择查询方式。平衡数据、武器一览与弦溯专题在预览前；角色与地图共用一个预览区，各自保留筛选和阅读位置。
- 首页组合式快捷入口把「编辑」放在六个位置的同一张卡内；独立按钮样式仍分开显示。资料预览把「全部角色／全部地图」放在预览卡标题行。阵营选项可换行，地图预览和「全部地图」共用可搜索的纵向模式选择器，但各自保存选择和浏览位置；预览图片仍可横向滑动。
- 「更多资料」的四个分类各用一张可点击的柔光卡，宽度允许时按阅读顺序分两列，窄屏和大字号改为单列横排。玩法等二级目录的可折叠分组有至少 48dp 高的标题点击区，保留展开状态；长入口名可换行。
- 首页顶栏初次在页首展示大标题，向上滚动折叠，回到顶部展开，返回沿用已有顶栏状态。右上角不放「完整导航」。有壁纸时沿用 2.2.4（`51e9b62`）的大标题：展开和前 8% 折叠不绘制顶栏底色，让壁纸连续；之后才渐显遮罩，完全折叠时玻璃模式为 28%、普通模式为 78%。无壁纸时使用 Material 默认顶栏。
- 角色名下方由透明过渡到阵营色；首页地图与一览的图卡共用可增高的渐变名称区。地图一览在 360dp、364dp 常规字号都能显示双列；容不下两列或字号放大到 1.5 倍时，改用左侧缩略图和右侧可换行的名称。两种布局都只让图片参与详情转场。
- 快捷入口的「编辑」与设置页复用六槽编辑器。进入不写偏好；旧配置按首页实际显示的六项初始化，已用项可交换，不会自动加入新的专题。搜索别名（例如「搜打撤」）或按组纵向浏览候选，确认保存才同步顺序与展示样式。
- 当两处编辑器各有草稿时，保存只合并本次修改的字段；两个草稿把顺序改成不同结果时，需明确选择是否替换。从搜索里的地图模式进入按模式标识定位，不修改通用地图一览的筛选。下载设置的系统目录选择器只填入草稿，「保存」才更改下载位置。
- 首页查询与搜索结果共享输入状态；清空或收起后，退场结果的迟到点击不能触发跳转。地图搜图遇到同名缺图时继续查找有图记录，空串也不能盖过详情自己的回退图。退出角色／地图详情后，旧回调不能在列表上打开 WebView。
- 首页和角色网格只在 RESUMED、当前路由未遮挡且共享转场结束时预取可见立绘及最多两个邻近项；拖动抽屉、打开生日弹窗或滑动列表会取消，恢复后延迟 160ms。全局预算最多两个，成功／失败／取消都释放在途名额。地图仍按卡片加载，地图名和渐变留在原卡片，只有 16:9 图片参与详情转场。
- 有壁纸时，二级目录顶栏、「编辑／全部角色／全部地图」、首页搜索和两种快捷入口、直达卡、各二级目录按实际文字颜色保护对比度；不把这层常驻底色加在首页大标题上。Hub 卡片共用 `HubPanelMaterial`：开玻璃时在模糊之后绘制衬色，关闭时由普通卡片绘制，避免双重上色。折叠进度只在遮罩绘制时读取。
- 有壁纸地址且当前页、预测返回目标或尚未退场的页面需要采样时，Hub 才录制全屏背景；壁纸加载中和失败时仍有主题底色。无壁纸时直接提供纯色给玻璃，不录制窗口；没有玻璃读者时不创建采样层。跟随壁纸配色时由主题层取色，位图量化在后台执行。使用其他主题时只在打开主题色选择器后按需计算色样，不随首页启动。
- 首页在列表外按实际可用宽度统一决定快捷入口与目录列数；旋转、分屏和字号仍能改变列数，顶栏折叠不会改变宽度断点。单列目录直接按内容高度布局，多列保留等高。立绘是否进入列表视口只观察可见性变化；加载中的一组占位共用动画时钟，不对玻璃或转场降级。

## 下载站搜索

- 当前 search 客户端实例内 Wiki 元数据请求串行，每次实际请求结束后间隔至少 6.5 秒，失败/取消也保留间隔。
- 新鲜缓存立即返回，不占网络额度。排队时若已由其它请求填充缓存，也直接返回；文件/CDN 下载不进入该调度器。
- timeout 从真正开始请求时计时；排队与在途均可取消。
- 识别原始/代理包装的 429、567、HTML 风控与 MediaWiki 限流，进入冷却并拒绝 fallback 追打。
- 首次全台词索引仍按需；已有缓存可补漏。索引串行构建，失败保留最后成功数据，风控后停止而不是将所有剩余角色标失败。
- 限流不跨标签页/用户，不替代 Worker 上游限流，也不代表全站不会再遇到 EdgeOne。

## 回归与设备验收

自动检查入口：

```text
.\gradlew.bat :androidApp:testDebugUnitTest :androidApp:lintDebug :shared:jvmTest :desktopApp:test --offline
downloadPage: pnpm check / pnpm test:search / pnpm test:balance / pnpm test:worker / pnpm build
```

- 解析/请求检查仅使用本地假数据；请求调度测试使用 fake clock/fetch，没有批量请求 BWiki。
- 导航使用真正的 Compose SaveableStateHolder 进行无 UI 的 JVM 回归：页面移除恢复、注册表重建、重置隔离、最新回调。测试仅为 `android.os.Trace` 的设备追踪标记提供 no-op shim，没有全局开启 Android API 默认返回。
- 子代理独立复查又发现并补上了快捷方式覆盖、手拖抽屉录制和旧系统玻璃降级边界。
- 本地没有连接 Android 设备，也没有可用 AVD。短屏/折叠尺寸变化、TalkBack、关于页逐帧视觉效果、预测返回和帧耗时仍需设备确认。未声称帧率提升比例或“完美解决”。

### 阶段验证与发布基线

- 最初导航专项阶段 Android 300 项（9 项可选测试跳过），随后增加武器、图鉴及卡池回归；不要把这个阶段数量当作完整发布数量。
- 最终 Android/shared/Desktop、Lint、网页检查和发布产物以发布记录为单一基线，避免各专题维护多份易失效的总数。
- 修复后进行了独立交叉复查；`git diff --check` 无空白错误（Windows 行尾提示除外）。

## 2.1.25：平衡页文案（2026-11-03）

- Android 筛选弹层删除草稿、取消路径、重置生效时机和重复赛季预览的解释；操作统一为“重置筛选 / 应用筛选 / 取消”，地图及段位的不限条件使用“全部”。
- 赛季对比保留所选赛季、百分点单位和表现分的 S8 起始说明，删除“数值变化不代表角色强弱”；卡片的“原”改为“对比”，避免暗示只能与更早赛季比较。空状态改为简短的筛选建议。
- 查询、草稿应用／取消、重置默认值、排序和差值计算均未改变。平衡专项 16 项测试全部通过。用户在发布前反馈其它内容已测试无问题；这是用户验收，不是代理真机检查或全设备覆盖。网页平衡看板不在本次修改范围；版本、最终回归及发布状态以 [2.1.25 发布记录](releases/2.1.25.md) 为准。
