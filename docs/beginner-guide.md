# 新人入坑指南原生页

## 入口与阅读

“游戏延伸 → 实用指南”中紧邻“游戏设置（PC）”，路由为 `WikiRoute.BeginnerGuide` / `beginnerGuide`。全局搜索支持新人、新手、入坑、配置需求、最低/推荐配置、腾讯服、创梦服、国际服和 Steam。已有 PC 设置及 Tips 路由编码不变。

`feature/wiki/beginner/` 按 model / parser / source / api / Screen 划分。直接读取 `action=parse&page=新人入坑指南&prop=text|revid`，不复制成静态攻略。原生页按 Wiki 顺序展示章节、加粗、嵌套列表、下载平台标题与链接。配置表转换为逐行资料块，区分最低/推荐配置；合并字段显示联合标签，不将最低配置当推荐，也不将 Wiki 入坑观点改写成应用结论。SMW 隐藏注释（如 Steam 不再支持 Win7/8）显式保留且只出现一次。

修订 `120494` 将原四章扩充为八章，新增“这是一款怎样的游戏”“开始游戏前需要了解什么”“游戏设置建议”和“常见问题”。装备表以装备类型为行名，分别说明作用和新手须知；设置建议表以设置项目为行名，不代表游戏默认值。新手问答保留提问与相应答复，Hub 搜索可用“装备类型”“游戏设置建议”“常见问题”找到指南。

章节选择器可横向滚动，每章使用独立保存域记录正文位置，空缓存预取不清掉章节选择。每条段落/表格记录独立 lazy item；加载骨架匹配章节选择器和正文。共享顶栏提供刷新和 Wiki 原文，刷新失败保留原资料，来源标签明确为 Wiki。外部官网/Steam 链接用系统浏览器打开，Wiki 链接沿用站内打开方式；已验证的 Bilibili linkfilter URL 解包后只接受 HTTP(S)，拒绝可执行协议及带认证信息的 URL。

- JSON envelope 校验兼容 formatversion 1/2，要求标题匹配；**缓存写入前和读取后**检查正文结构。有效 HTTP 响应但结构错误且无好缓存时为 PARSE；无法获取且无缓存为 NETWORK。错误新数据不会替换好磁盘数据，回退保留离线标识及年龄。
- API 沿用 `CachedWikiApi` 的版本票据、清理注册与离线不永久 memo 规则；页面后台验证绕过内存缓存。cacheOnly 只有磁盘读，无图标/模块等补请求。
